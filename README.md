### 📒 Minha Agenda de Contatos - Streamlit
Este projeto é uma aplicação web simples de agenda de contatos desenvolvida com Streamlit, uma ferramenta para criação de interfaces web em Python de forma rápida e intuitiva.

## 💡 Funcionalidades
A agenda permite:

- ➕ Adicionar novos contatos com nome, telefone e e-mail.

- 📋 Listar todos os contatos cadastrados.

- 🔎 Buscar contatos pelo nome.

- ❌ Remover contatos da agenda.

- Todos os dados são armazenados em memória (session_state), ou seja, são temporários e serão perdidos ao recarregar a página.

## 🚀 Como Executar
- Certifique-se de ter o Python instalado (versão 3.7 ou superior).

- Instale o Streamlit:

```bash
pip install streamlit
```

# Execute a aplicação com o comando:

```bash
streamlit run app.py
```

O navegador será aberto automaticamente com a interface da agenda.

## 🧠 Conceitos Abordados
- Uso do st.session_state para persistência temporária de dados na sessão.

- Criação de menus interativos com st.sidebar.radio.

- Formulários com st.text_input, st.button e st.selectbox.

- Manipulação de dicionários Python para simular um banco de dados simples.
